# 更新日志（CHANGELOG）

## [0.2.0] — 2026-11-21（赛程取数并发与缓存提速）

功能级性能优化：代理聚合端点 + 缓存/并发模型调整，未做整体架构重构（minor 版本）。

### 本次改动

- **代理聚合端点**：新增 `GET /proxy/games/all`，内部并发拉取腾讯各联赛、WCBA、斯诺克等源并按 id 去重；前端首页与后台刷新只打这一条聚合端点，ESPN 走后台回填，避免一次性十几条请求打本地代理造成浏览器连接排队。
- **缓存模型**：赛程缓存合并为单键 `games:all`，旧碎键自动迁移清理；增加二级内存缓存（TTL 600s）；半龄数据后台静默刷新；快源先行渲染、ESPN 后台补齐。
- **并发与超时**：三源并发、适配器联赛内并发、ESPN 日期桶并发；腾讯三日期桶由串行改并发；聚合单源 3s 超时降级；代理侧 30s 短缓存；ESPN 4s 超时；前端 XHR 统一 8s 超时封装。
- **去重**：`_mergeById` 按 id 合并去重，重叠联赛不出现双份卡片。

### 复测口径

- 冷启动首屏约 3.1s / 32 张；8s 内后台回填缓存 179 场（CBA / 英超 / 西甲 / 意甲 / 德甲 / 欧冠 / ATP / WCBA / 斯诺克 / NBA）。
- 热刷新约 0.02s / 41 张；标签切换 < 0.5s；腾讯详情抽测正常、控制台无报错。

## [0.1.0] — 2026-11-19（首个封板基线）

首个固定初始版本。三端（PC Electron / 安卓 WebView / 浏览器）共用同一单文件页面，数据经统一适配层多源接入。

### 功能范围

- **运动分组**：篮球、足球、网球、桌球、电竞；两级标签（运动类别 + 联赛/项目）。
- **赛程与比分**：今日 / 明天 / 后天 / 近 3 天筛选，新到旧 / 旧到新排序，按联赛分组与比赛状态筛选；未开赛 / 进行中 / 完场状态区分。
- **联赛详情**：积分榜、赛程表、淘汰赛树状图；球队近 5 场 W/L 战绩。
- **比赛详情**：首发与替补名单、实时技术统计、回合动作流（默认最近 8 条，更早折叠）、场地缩略图点位与持球人、球员榜。
- **队名与译名**：中文队名两行折行规则（地名 + 冠名）；球员 / 球队名中英切换；中超队名英文转中文。
- **界面**：原生 JS + hash 路由，无框架构建；内联简中 / 繁中 / 英文三语；localStorage 缓存与档位、缓存清理；设置弹窗（通用 / 数据源）；广告位预留。
- **多源适配**：ESPN 直连、本地代理回退（WCBA）、腾讯体育转发（CBA / 足球 / 网球），逐级回退、重叠联赛去重。

### 数据源口径

- ESPN 公开 API：NBA、WNBA、NCAA 等可直连项目。
- 本地代理（`proxy/server.js`，Node 零依赖，默认 `127.0.0.1:8787`）：
  - 旧官网回退：WCBA；
  - 腾讯体育转发：CBA、英超 / 西甲 / 意甲 / 德甲 / 中超 / 欧冠 / 日职联、WTA / ATP / 美网 / 温网 / 法网。
- 仅取公开免费结构化数据；不携带登录态，不抓取付费内容与视频回放。
