# 三端架构与适配层说明（v0.1.0 基线）

## 整体架构

```
            ┌──────────────────────────────────────────┐
            │  视图层（单文件 HTML + 原生 JS，无构建）    │
            │  hash 路由 / 状态对象 / 重渲染 / 内联 i18n │
            └────────────────────┬─────────────────────┘
                                 │ SportsProvider 统一出口（CachedProvider 串联 + 本地缓存）
            ┌────────────────────▼─────────────────────┐
            │  适配层 Adapter（按联赛/前缀分流，逐级回退）│
            │  EspnAdapter   ESPN 公开 API（直连）       │
            │  ProxyAdapter 本地代理回退（WCBA 等）      │
            │  TencentAdapter 本地代理转发腾讯体育       │
            └────────────┬───────────────┬─────────────┘
                         │               │
              ┌──────────▼──────┐  ┌────▼─────────────────┐
              │ 本地代理 proxy/  │  │ 三端运行环境          │
              │ server.js（Node）│  │ PC Electron / 安卓 WebView / 浏览器 │
              └─────────────────┘  └──────────────────────────────┘
```

- 界面与数据解耦：所有数据经 `SportsProvider` 出口取数；新增数据源只加 Adapter，不改视图。
- 联赛 / 运动配置（`SPORTS`、`LEAGUES`、`SPORT_CFG`）可扩展新运动与联赛；队名拆分、译名表、统计列均集中在前端规则层。

## 适配层与数据源

| Adapter | 数据源 | 覆盖范围（0.1.0） | 取数方式 |
| --- | --- | --- | --- |
| EspnAdapter | ESPN 公开 API | NBA、WNBA、NCAA 等可直连项目 | 浏览器/WebView 直连 |
| ProxyAdapter | 本地代理回退 | WCBA 等旧官网 HTML/JSON | 经 `127.0.0.1:8787` 转发 |
| TencentAdapter | 本地代理转发腾讯体育 | CBA、英超/西甲/意甲/德甲/中超/欧冠/日职联、WTA/ATP/美网/温网/法网 | 经 `127.0.0.1:8787` 转发 |

- 重叠联赛由腾讯适配器优先，ESPN 跳过已被腾讯覆盖的联赛，避免双份卡片。
- 单场详情按 id 前缀分流：`espn-` 走 ESPN、`tx-` 走腾讯、其余走代理回退。
- 未接入或无当期赛程的项目走空态「联赛数据待接入」，不报错、不写空缓存。

## 本地代理（proxy/server.js）

- 零第三方依赖，Node 18+ 内置 `http`/`fetch`；默认端口 `8787`，可用 `PROXY_PORT` 覆盖。
- 作用：代为请求不开放 CORS 的国内公开源，解析成前端统一结构后返回，并补 `Access-Control-Allow-Origin: *`。
- 端点：`/proxy/<league>/games|league`（旧官网回退）、`/proxy/tencent/games|league|game`（腾讯转发）、`/proxy/raw?url=`（通用备用）。
- 模块两用：直接 `node server.js` 启动；被 Electron 主进程 `require` 时导出 `startProxy(port)`，不自行监听。

## PC 端（Electron）

- `pc/main.js` 创建 `BrowserWindow`，`loadFile` 指向 `resources/赛事中心.html`。
- 启动时在主进程内嵌拉起本地代理（`proxy.js`），监听 `127.0.0.1:8787`；端口被外部代理占用时静默沿用现有服务，不报错；窗口关闭时关闭代理。
- 打包：`electron-builder` 产出 NSIS 安装包、便携 exe 与绿色 zip；`proxy.js` 与页面一并打入 `app.asar`。

## 手机端（WebView 混合壳）

- 原生 Android 工程，`MainActivity` 内一个 WebView，离线加载 `assets/index.html`。
- 手机端无 Node 运行时，无法内嵌本地代理：腾讯/旧官网等需代理的源在手机端走空态；可直连的公开源正常。
- 页面不可见时暂停 WebView 与 JS 计时器，回前台恢复；返回键优先 WebView 历史回退。

## 数据更新分层

| 类别 | 示例 | 刷新策略 |
| --- | --- | --- |
| 实时类 | 比分、节次/时钟、在场名单、即时技术统计 | 分钟级轮询或服务端推送 |
| 榜单类 | 积分榜、球员榜、近 5 场战绩、排名 | 每轮赛后或每日更新 |
| 基础资料 | 名单、位置、教练、译名 | 有变动即更新 |

## 当前限制（0.1.0 基线）

- 数据均来自公开免费源；付费/登录态内容、视频回放不抓取。
- 日职联、WTA、美网/温网/法网的腾讯赛事 ID 待有赛程时补录，当前空态。
- CBA 等腾讯源暂无投篮坐标与逐回合动作流；场地点位与动作流待上游补坐标后呈现。
- 完整逐回合球权 / 坐标类实时数据需付费专业数据源，免费档一般只到比分、节次、时钟与累计统计。
